# icpm2024
This repository contains the supplementary materials for the paper *Can We Leverage Process Data from ERP Systems
for Business Process Sustainability Analyses?* by Dominik Schäfer, Finn Klessascheck, Timotheus Kampik, and Luise Pufahl.

The final meta-dataset containing all 422 entries is found in the file *meta-dataset.csv*.

The Appendix is found in the file *Appendix.pdf*.
